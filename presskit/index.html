Sobre o estúdio / About

A Zindie Game Studio é o estúdio de um único desenvolvedor brasileiro, que faz jogos independentes no GameMaker — do código ao 3D, da arte à publicação.

Zindie Game Studio is a one-person studio from Brazil making independent games in GameMaker — code, art, 3D and publishing, all done solo.
